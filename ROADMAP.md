## Phase 1: Core Gameplay ✅

*Goal: Functional hero hatching, deployment, and basic battle system*

- [x] Project setup with Next.js + TypeScript + Tailwind
- [x] Landing page with hero section, features, roadmap, token section
- [x] Wallet connection with 0G testnet detection
- [x] Hero generation system (7 classes, 6 rarities, stat allocation)
- [x] Basic battle system with grid generation
- [x] Hero detail view with stat display
- [x] Energy system with regen and potions
- [x] Difficulty selection (Easy / Advanced / Nightmare)

---

## Phase 2: AI Evolution ✅

*Goal: Heroes that learn, remember, and evolve*

- [x] AI Decision Engine with action scoring system
- [x] Action scoring formula: Base + Intelligence + Personality + Traits + Memories + Team + Threats + Noise
- [x] Stuck detection and path recalculation
- [x] Team AI with loyalty-based grouping
- [x] Memory system — heroes remember battles, loot, near-death escapes
- [x] Trait unlock system (12 traits with conditional requirements)
- [x] AI stat evolution through battle performance
- [x] Learning rate modifier for XP gain
- [x] Personality-driven behavior (7 trait dimensions)

---

## Phase 3: Marketplace 🔄

*Goal: Player-driven economy with trading*

- [ ] Marketplace interface with listings grid
- [ ] Hero listing and trading
- [ ] Equipment and cosmetic listing
- [ ] Potion trading
- [ ] Buy/sell/cancel workflow
- [ ] Marketplace fee system (2.5%)
- [ ] Admin fee configuration
- [ ] Remote sync via Supabase

## Phase 4: Legacy System 📋

*Goal: Hero retirement and generational progress*

- [ ] Legendary hero requirements (level 10, all stats >= 70)
- [ ] Legacy Core generation on retirement
- [ ] Legacy Core tiers (I-V)
- [ ] Legacy Core application to new heroes
- [ ] Memory and trait preservation
- [ ] DNA fragment storage

---

## Phase 5: Bloodline System 📋

*Goal: Genetic inheritance across generations*

- [ ] Stat inheritance (30-70% from parent)
- [ ] Trait inheritance (40% chance per trait)
- [ ] Mutation mechanics (10-15% chance per stat)
- [ ] DNA quality, potential, mutation chance, legacy affinity stats
- [ ] Bloodline record tracking
- [ ] Generation counter and family tree

---

## Phase 6: Onchain Integration 📋

*Goal: Full blockchain integration with 0G*

- [ ] 0BOMB smart contract deployment
- [ ] Fragment to token conversion
- [ ] On-chain hero NFT verification
- [ ] Equipment and cosmetic minting
- [ ] Cryo Pod system for preserving heroes on-chain
- [ ] Gacha system with randomized loot boxes
- [ ] Token burn mechanisms
- [ ] DAO governance for economy parameters
