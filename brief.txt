## Game Lore
Humanity's colony ship crash-landed on a hostile alien planet. Thousands of human survivors remain frozen inside Cryo Pods. Players awaken survivors and send them into dangerous sectors to clear maps, fight alien creatures, collect resources, learn from experiences, and build powerful bloodlines.

## Core Game Loop
Acquire Cryo Pod → Hatch Hero → Deploy Hero → Clear Map → Fight Aliens → Avoid Hazards → Collect Loot → Gain XP → Gain Memories → Increase Intelligence → Unlock Traits → Become Legendary → Create Legacy Core → Transfer Knowledge → Build Bloodline
