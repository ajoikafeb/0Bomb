## Key Architecture Decisions
- All pixel art = React SVG components (crispEdges), zero external images
- Game state via localStorage (Supabase ready when configured)
- Phaser 3 with dynamic SSR-safe import (`ssr:false`)
- Single-file landing page (`page.tsx`), modular game pages

## Core Systems (All Live)
- **Wallet**: Connect/disconnect, auto-reconnect, balance display
- **Heroes**: Hatch, deploy, play, AI decision engine, XP, leveling
- **Memories**: Recorded from gameplay (Killed Alien, Found Rare Loot, etc.)
- **Intelligence**: Stats grow through actions (Combat, Survival, Loot, etc.)
- **Traits**: Auto-unlock (Lava Survivor, Treasure Hunter, Bomb Master, etc.)
- **Legacy**: Lv10+ & intel 90+ → Legendary → Gen2 child hero
- **Energy**: Per-hero energy with regen, potions
- **Equipment/Cosmetics**: Slot-based, generated, tradeable
- **Marketplace**: List/buy heroes, equipment, cosmetics
- **Cryo Pods**: 5 rarities with hatch gacha
- **Withdrawals**: Request fragments, admin confirm/reject → inbox notification
- **AI**: BFS escape pathfinding, wall bombing, enemy evasion
- **Audio**: 128-step procedural music sequencer (pad, arp, lead, drums)
